# Content demo script

Use local seeded accounts only. Reset the dedicated demonstration database before rehearsal; use the generated post number, not a hard-coded new ID. Record the desktop and phone views. This is the Content segment for the team's video, not a claim that the entire team's video has been recorded.

| Time | Action | Suggested narration |
|---|---|---|
| 0:00–0:15 | Mandy: New post, type a short note, choose Trade, add two local sample images; leave switches off; publish | “A student can publish a note with up to six images. Identity and audience are independent choices. This post is anonymous and visible only to HKU.” |
| 0:15–0:25 | Copy its generated URL; switch to Wing from CUHK and open it | “Visibility is checked on the server. A student from another university receives the same not-found page as for a missing post.” |
| 0:25–0:45 | Newbie: open #600012; comment; reply to Bob | “Comments use a stable identity for each post. Newbie becomes Dave here, because Alice, Bob and Carol already participated. A reply retains that identity and links to the original comment.” |
| 0:45–0:55 | Kelvin: open #600012 and show Host; toggle like/watch | “The author is Host. Likes and watches are separate, and repeated requests do not duplicate either record.” |
| 0:55–1:10 | Mandy: open #600005, open an image, switch with arrows, close; resize phone/desktop | “The same site adapts to computers and phones. The viewer supports keyboard and touch, and closing it returns to the same reading position.” |
| 1:10–1:20 | Mandy: My comments, select one; show reply anchors and a deleted/hidden placeholder | “Personal comments link directly to the right place. Deleted comments keep their position so existing replies remain understandable.” |
| 1:20–1:45 | Show the alias transaction and concurrency result from SQL_CARD.md | “A row lock serializes first comments on the same post. In our HTTP test, all twenty requests succeeded with unique aliases. Without that lock, competing transactions attempt the same next number.” |
