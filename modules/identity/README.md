# identity module

Owner: Michael (coordinator). This folder holds the identity module: sign-up with a university e-mail and a 6-digit code, login and logout, password reset, the Me hub (avatar, handle, university, four counts and the menu), profile, settings, the public About, Contact, Terms and Privacy pages, and the admin user list. Everything about it (routes, SQL, pages, tests, the build plan and a ready-made prompt for a coding agent) is in [`docs/modules/identity/DEV_GUIDE.md`](../../docs/modules/identity/DEV_GUIDE.md); the tested SQL is in [`queries.sql`](../../docs/modules/identity/queries.sql) and what users see is in [`USER_GUIDE.md`](../../docs/modules/identity/USER_GUIDE.md). `secrets.js` holds the non-SQL helpers (codes, hashes, handles, `safeNext`), `queries.js` every SQL statement, and `public/` the Me banner and a small stylesheet. Only change files in this folder and in `docs/modules/identity/` (see `AGENTS.md`).
